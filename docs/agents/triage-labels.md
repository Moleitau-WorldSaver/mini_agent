# Triage 标签

技能使用五个规范 triage 角色。本文件把角色映射到本仓库 tracker 的实际字符串。

| 技能内的标签 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 Issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已充分描述，可交给自主 agent |
| `ready-for-human` | `ready-for-human` | 需要人类实现 |
| `wontfix` | `wontfix` | 不会处理 |

在本地 tracker 中，这些字符串同时用作 issue 文件里的 `Status:` 值。需要调整时，编辑上表"本仓库的标签"列。
